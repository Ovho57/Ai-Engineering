# Core Foundations — Both AI Fields Need These

This is the **shared foundation** for both paths. Do not skip it.

## Programming and computer science
Both paths need:
- Files, folders, terminal, and how programs run.
- Python variables, conditions, loops, functions, classes.
- Algorithms, data structures, and debugging.
- Git and GitHub.
- Reading errors and testing code.

## Python
Learn numbers, strings, booleans, lists, dictionaries, loops, functions, imports, exceptions, classes, files, virtual environments, packages, and basic tests.

## Math and logic
Learn algebra, functions, vectors, matrices, dot products, tensor shapes, probability, statistics, derivatives, gradients, and gradient descent.

Readable formulas:

    dot product = (a1 × b1) + (a2 × b2) + ... + (an × bn)

    new parameter = old parameter - (learning rate × gradient)

## Data
Understand CSV, JSON, text, images, cleaning, validation, train/validation/test splits, data leakage, and privacy.

## AI basics
Understand AI vs machine learning vs deep learning; models, weights, biases, inference, training, tokens, embeddings, context windows, evaluation, and hallucinations.

## APIs and web
Learn HTTP, GET/POST, JSON request/response, authentication, API keys, timeouts, retries, rate limits, and errors.

Never commit passwords, API keys, or private tokens to GitHub.

## Software engineering
Use readable names, modules, functions, tests, logging, Git commits, documentation, and privacy-aware design.

## Shared beginner projects
1. Python calculator.
2. JSON reader/writer.
3. Rule-based chatbot.
4. Program that calls an API and handles errors.
5. Small documented GitHub project.

## How the fields differ
**AI Engineering / ML:** deeper focus on data, training, neural networks, evaluation, and model deployment.

**AI Agent Engineering:** deeper focus on LLM APIs, tools, workflows, state, retrieval, and reliable applications.

Both paths require these core foundations.
