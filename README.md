## Recommended tools

Python 3.11+, VS Code, Git, NumPy, Matplotlib, pandas, scikit-learn, PyTorch, and Jupyter/Colab. Install tools as lessons require them.

## How to study together

Read slowly, type examples yourself, explain concepts to each other, complete exercises, and build projects. Do not just copy code—predict what it will do, run it, and explain the result.

Small neural networks can run on ordinary computers. Training frontier-scale models requires far more compute and data.
