Tools: Python 3.11+, VS Code, Git, NumPy, Matplotlib, pandas, scikit-learn, PyTorch, Jupyter/Colab. Install as you go.

Study in order, type examples yourself, explain concepts to your partner, and complete exercises. Small neural networks are accessible on ordinary computers; frontier-scale training needs vastly more compute and data.
