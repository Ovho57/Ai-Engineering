# 00 — Start Here

Welcome to Book 2: AI Agent Engineering.

You will learn to build applications that receive a request, use a model, call approved tools, track relevant state, retrieve documents, check results, and respond.

## A basic agent flow

    user request
        ↓
    application receives it
        ↓
    model proposes response or approved tool
        ↓
    application validates and runs tool
        ↓
    tool result returns to model
        ↓
    final response

An agent is not magic. It is software built around a model, instructions, tools, and control logic.

## Study together
1. Read a chapter.
2. One person explains it without looking.
3. The other gives an example.
4. Both type and run the code.
5. Switch roles.
6. Write down questions.

## Safety rule
Use fake data or a sandbox. Require confirmation before actions affecting people, accounts, money, or important files.

Before beginning, be comfortable with Python functions, JSON, API requests, terminal, and Git.
